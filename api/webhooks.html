Configure Webhook Endpoint

We will send a POST request with an HMAC-SHA256 signature header whenever message status updates.

Webhook Signature Verification

Every webhook payload includes the header X-MailBridge-Signature.

Node.js (Express / Crypto) 
const crypto = require('crypto');

app.post('/webhooks/mailindia', (req, res) => {
  const signature = req.headers['x-mailbridge-signature'];
  const secret = process.env.MAIL_INDIA_WEBHOOK_SECRET;

  const expected = crypto
    .createHmac('sha256', secret)
    .update(JSON.stringify(req.body))
    .digest('hex');

  if (signature !== expected) {
    return res.status(401).send('Invalid signature');
  }

  const { event, id, recipient } = req.body;
  console.log('Received event:', event, 'for', recipient);
  res.status(200).send('OK');
});
ℹ️
Instant Retries: If your server returns an HTTP status code outside of 2xx, MAIL INDIA retries delivery 3 times with exponential backoff.
