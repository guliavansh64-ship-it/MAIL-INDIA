Mail India is an Indian email infrastructure and API platform designed for developers, startups, and growing teams. It enables reliable transactional email dispatch, Google Workspace relay integration, SMTP delivery, and real-time monitoring through a unified platform.
You make an HTTP POST request to our REST API endpoint with your API key in the authorization header and recipient details in the JSON body. Mail India validates the request, checks wallet credits, signs the email, and transmits it via the configured relay route.
Once registered and logged in, navigate to the API Keys section inside the console. Click "Create New Key", assign an optional label, and copy your secret key. For security, keys are hashed and shown only once.
